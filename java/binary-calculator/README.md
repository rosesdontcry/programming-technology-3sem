# Калькулятор систем счисления

Настольный калькулятор на Java 17 и JavaFX. Он поддерживает двоичную, восьмеричную, десятичную и шестнадцатеричную системы счисления.

## Запуск

Нужны JDK 17, Maven и графическая среда. Из папки `java/binary-calculator` выполните:

```bash
mvn javafx:run
```

При первом запуске Maven загрузит зависимости. Запуск тестов:

```bash
mvn test
```

Тесты вычислений выполняются и без экрана. Тесты JavaFX-интерфейса автоматически пропускаются в headless-окружении без настроенной платформы Monocle.

## Работа с калькулятором

- В каждой строке левое поле — двоичное число; правое поле использует основание из выпадающего списка. Основания строк выбираются независимо.
- Оба поля операндов можно редактировать. Используйте точку для дробной части и `-` для отрицательных чисел. В шестнадцатеричной системе допустимы буквы `A–F` и `a–f`. Если длинная запись видна не целиком, переместите курсор внутри поля, чтобы увидеть остальные цифры.
- Результат пересчитывается автоматически. Его поля предназначены только для чтения, но систему счисления результата можно менять.
- При операции `^` первое число — основание, второе — показатель. При `√` первое число — степень корня, второе — подкоренное число. Нечётные целые корни отрицательных чисел поддерживаются.
- `mod` — остаток от деления с усечением частного к нулю, как оператор `%` в Java. Например, `-5 mod 3 = -2`. Значение `0^0` равно `1`.
- Значок `≈` рядом с полем означает, что отображена приближённая запись. Например, десятичная `0.1` имеет бесконечную двоичную запись. Точные операции `+`, `−`, `×`, `÷` и `mod` выполняются над рациональными значениями, а не над обрезанной записью из поля. Иррациональные корни и некоторые дробные степени вычисляются приближённо.

## Точность и ограничения

При выводе дроби после начальных нулей используется до 32 значащих цифр в соответствующей системе счисления; при необходимости последняя цифра округляется. Ненулевое число не выводится как ноль только потому, что не поместилось в доступную точность.

Модуль операнда и результата не должен превышать `2^53` (`9007199254740992`). Ввод ограничен 2112 цифрами, дробная часть отображения — 2048 цифрами. Очень длинная вставка обрезается по длине поля и не участвует в вычислении до исправления. Для целых степеней также ограничен размер вычисления: показатель до 16384 и внутренние целые числа до 65536 бит; случаи с основаниями `0`, `1` и `-1` обрабатываются отдельно.

Если ввод или результат выходит за ограничения, операция не определена или ненулевое значение невозможно отобразить в пределах точности, результат остаётся пустым. После исправления ввода вычисление возобновляется автоматически; сообщения об ошибках не выводятся.
