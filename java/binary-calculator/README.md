# Калькулятор систем счисления

Настольный калькулятор на Java 17 и JavaFX. Поддерживает двоичную, восьмеричную, десятичную и шестнадцатеричную системы счисления.

## Запуск

Нужны JDK 17, Maven и графическая среда. Из папки `java/binary-calculator`:

```bash
mvn javafx:run
```

При первом запуске Maven загрузит зависимости. Тесты запускаются командой:

```bash
mvn test
```

Тесты вычислений работают без экрана. Тесты интерфейса пропускаются, если нет графической среды или настроенной платформы Monocle.

## Работа с калькулятором

- В каждой строке левое поле — двоичное число, правое — число в выбранной системе. Основания строк выбираются независимо.
- Оба поля операндов можно редактировать. Для дробной части используйте точку, для отрицательного числа — `-`. Для шестнадцатеричных цифр подходят `A–F` и `a–f`.
- Результат пересчитывается автоматически. Его нельзя редактировать, но можно менять систему счисления результата. Если запись длинная, переместите курсор внутри поля, чтобы увидеть остальные цифры.
- При `^` первое число — основание, второе — показатель. При `√` первое число — степень корня, второе — подкоренное число. Нечётные целые корни отрицательных чисел поддерживаются.
- `mod` — остаток от деления со знаком первого числа, как `%` в Java: `-5 mod 3 = -2`. Значение `0^0` равно `1`.

## Как устроен код

- `BinaryCalculator` создаёт окно и кнопки, а при изменении ввода вызывает пересчёт.
- `NumberEntryRow` содержит два поля одной строки и выбор основания. Флаг `syncing` не даёт полям бесконечно обновлять друг друга; `finally` обязательно возвращает флаг обратно. Фильтр ввода использует шаблон: необязательный минус, разрешённые цифры и необязательная точка с дробной частью.
- `Fraction` хранит число как числитель и знаменатель типа `BigInteger`. Конструктор сокращает дробь и проверяет предел: например, `8/10` хранится как `4/5`.
- `CalculatorLogic` разбирает ввод, переводит числа и выполняет операции. При переводе дробной части он последовательно умножает остаток на основание новой системы. Операция выбирается через `switch`.

Например, `0.8 − 0.7` считается как `8/10 − 7/10 = 1/10`, поэтому результат равен `0.1`. Целые степени и точные корни тоже вычисляются через дроби. Для дробных степеней и корней без точного результата используется `Math.pow`.

В шаблоне фильтра `(?i)` означает отсутствие различий между заглавными и строчными буквами, `-?` — необязательный минус, `[...]` — допустимые цифры, `*` — любое их количество, а часть с `\\.` проверяет необязательную дробную часть.

## Точность и ограничения

Дроби, которые невозможно записать конечным числом цифр, и некоторые корни и степени округляются **без отдельного знака**. При этом введённые рациональные значения и операции `+`, `−`, `×`, `÷`, `mod` хранятся и вычисляются точно, не по обрезанному тексту второго поля.

При выводе после начальных нулей используется до 32 значащих дробных цифр, максимум 2048 дробных позиций. Ненулевое число не выводится как ноль только потому, что не поместилось в точность.

Модуль операнда и результата не должен превышать `2^53` (`9007199254740992`). Ввод ограничен 2112 цифрами; очень длинная вставка обрезается и не участвует в вычислении до исправления. Для целых степеней ограничен размер вычисления: показатель до 16384 и внутренние целые числа до 65536 бит; основания `0`, `1` и `-1` обрабатываются отдельно.

Если ввод или результат выходит за ограничения, операция не определена или ненулевое значение невозможно отобразить, результат остаётся пустым. После исправления ввода вычисление возобновляется; сообщения об ошибках не выводятся.
